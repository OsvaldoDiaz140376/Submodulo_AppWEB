🧑‍🏫Teoría que explica el profesor

De Python a JavaScript, el árbol del DOM y cómo responde la página a lo que hace la persona.

Puente Python → JS
🔁Puente Python → JS

print → console.log, == → ===, lista → arreglo, diccionario → objeto, for → forEach, lambda → función flecha y sangría → llaves.

💡 Pista rápida: Pasa de un idioma a otro: las ideas son las mismas.

El DOM
🌳El DOM

Tu HTML se convierte en un árbol de objetos. JavaScript cambia el árbol, no tu archivo .html. Con <script src="app.js" defer> corre cuando el HTML está completo.

💡 Pista rápida: Sin defer, querySelector devuelve null.

textContent vs innerHTML
🛡️textContent vs innerHTML

innerHTML interpreta HTML: un dato con <img onerror> se ejecutaría (XSS, OWASP A03). Regla del curso: lo que escribe una persona se muestra con textContent.

💡 Pista rápida: Si viene de una persona, textContent.

Eventos
⚡Eventos

Tres preguntas: ¿en qué elemento?, ¿qué evento? (click, input, keydown, submit), ¿qué hago? Se pasa la función, no se llama: addEventListener('input', filtrar).

💡 Pista rápida: Con paréntesis la función se ejecuta ya, no al escribir.

Sesión 2 · Formularios y datos

Partes C y D🔵 ERPReto R5.1 (2.ª mitad)

🎬Lo que hacen

Validan todos los formularios de su ERP con mensajes claros y accesibles, y hacen que cada uno guarde sus registros y los muestre en una tabla.

Predice
🔮Predice

Dos predicciones: la conversión de texto a número (false NaN 0) y números con JSON (97.50 false {"total":97.5}).

💡 Pista rápida: Lo que escribe una persona siempre llega como texto.

Prácticas guiadas
🟢Prácticas guiadas

Alta de cliente con validación y cotizador con total en pesos y memoria (localStorage). No suman puntos.

💡 Pista rápida: Cambian de rol entre ejercicios.

Reto R5.1 · parte C
🅲Reto R5.1 · parte C

Una función para cualquier formulario: novalidate, preventDefault, mensaje en español junto al campo, aria-invalid, aria-describedby y foco al primer error.

💡 Pista rápida: Recorre input, select, textarea: no escribas nombres de campos a mano.

Reto R5.1 · parte D
🅳Reto R5.1 · parte D

Cada formulario válido guarda un registro en localStorage (clave erp_<id>) y dibuja debajo la tabla «Registros guardados». Al recargar siguen ahí.

💡 Pista rápida: Cada campo se guarda por su name; el dato se muestra con textContent.

Si algo falla
🛟Si algo falla

Sin e.preventDefault() la página se recarga; sin name el campo no se guarda; sin novalidate no salen tus mensajes.

💡 Pista rápida: Revisa los pattern, min y max de tus formularios.

🧑‍🏫Teoría que explica el profesor

Validar con respeto y llevar un dato de la pantalla a la memoria del navegador y de regreso.

Validar con respeto
🧾Validar con respeto

Ciclo: submit → preventDefault() → revisar validity → mensaje junto al campo + aria-invalid + foco al primer error (WCAG 3.3.1, 3.3.2, 2.4.3). Sin alert().

💡 Pista rápida: Validar en el navegador mejora la experiencia, no protege el sistema.

Números y formato
🔢Números y formato

Number(texto) convierte, toFixed(2) redondea y Intl.NumberFormat('es-MX', {style:'currency', currency:'MXN'}) da $170.00.

💡 Pista rápida: '2' + '3' da '23': convierte antes de calcular.

JSON y localStorage
💾JSON y localStorage

Un dato tiene tres vidas: se captura (campo.value), se guarda (JSON.stringify → localStorage.setItem) y se muestra (getItem → JSON.parse → tabla). Usa try/catch.

💡 Pista rápida: localStorage solo guarda texto y no es seguro para datos sensibles.

Tabla segura
🧱Tabla segura

insertRow() e insertCell().textContent = dato: una etiqueta <img onerror> se ve como texto y no se ejecuta.

💡 Pista rápida: El autoverificador prueba un ataque XSS real.

🔤 Glosario de la semana

  • DOM (Document Object Model)Árbol de objetos que el navegador crea a partir de tu HTML. JavaScript lo lee y lo cambia; tu archivo .html no se modifica.
  • `defer`Atributo de <script> que espera a que el HTML esté completo antes de ejecutarlo, para que existan los elementos.
  • `querySelector` / `querySelectorAll`Buscan elementos con selectores de CSS. El primero devuelve el primer elemento (o null); el segundo, una lista.
  • `textContent`Propiedad que lee o cambia el texto de un elemento. Seguro: lo escrito se muestra como texto.
  • `innerHTML`Propiedad que interpreta el valor como HTML. Con datos de una persona es peligroso (XSS).
  • XSSAtaque en el que un dato malicioso (por ejemplo <img onerror=…>) se ejecuta en la página. OWASP Top 10 A03 Inyección.
  • `classList`Permite agregar, quitar o alternar clases (add, remove, toggle, contains) sin tocar estilos desde JavaScript.
  • `hidden`Atributo que oculta un elemento. Con [hidden] { display: none !important; } en tu CSS se oculta siempre.
  • `createElement`, `append`, `before`Crean un elemento nuevo (aún fuera de la página) y lo colocan al final, antes o después de otro.
  • EventoAlgo que ocurre en la página: click, input, keydown, submit.
  • `addEventListener`Le dice al navegador qué función ejecutar cuando ocurra un evento. Se pasa la función, no se llama.
  • Objeto del evento (`e`)Dato que recibe la función: e.key es la tecla, e.target quién lo provocó.
  • `aria-live`Región que un lector de pantalla anuncia cuando cambia su texto (por ejemplo, «3 de 12 registros»). WCAG 4.1.3.
  • `normalize('NFD')`Separa letras y acentos para poder quitarlos y comparar «café» con «cafe».
  • `novalidate`Apaga los globos de error del navegador para mostrar tus propios mensajes.
  • `preventDefault()`Evita la acción normal del evento; en submit evita que la página se recargue.
  • `validity`Objeto del campo que dice por qué falló: valueMissing, typeMismatch, patternMismatch, rangeUnderflow, rangeOverflow.
  • `aria-invalid` / `aria-describedby`Avisan a los lectores de pantalla que un campo tiene error y enlazan el campo con su mensaje. WCAG 3.3.1.
  • `Number()` / `toFixed()`Convierte texto a número (o NaN) y redondea a un número de decimales (devuelve texto).
  • `Intl.NumberFormat`Da formato a números, por ejemplo $170.00 con es-MX y MXN.
  • JSONFormato de texto para datos. JSON.stringify convierte un objeto o arreglo a texto y JSON.parse regresa.
  • `localStorage`Memoria del navegador que guarda texto y se conserva al recargar. Puede fallar y no es seguro para datos sensibles.
  • `try/catch`Intenta ejecutar código y, si falla, ejecuta un plan B en lugar de romper la página.
  • `insertRow` / `insertCell`Agregan filas y celdas a una tabla; con textContent muestran datos sin riesgo.
  • `name` (de un campo)Nombre con el que se guarda el valor del campo. Sin name, no se guarda en el registro.
  • Consola (F12)Panel del navegador donde salen console.log y los errores en rojo con la línea.
